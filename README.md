## `whoami`

Cybersecurity consultant and computer engineer. I work on two sides of the field:

- **For clients** — security governance, risk analysis, hardening and regulatory compliance (ENS, NIS2, ISO 27001/22301) for public- and private-sector organisations, and more recently offensive security work.
- **Research** — pulling firmware off devices, reverse engineering embedded binaries and hunting vulnerabilities in IoT.

Associate of ISC2 (CCSP) · ISO 22301 Lead Auditor · currently pursuing the Inter-University Master's in Cybersecurity (MUNICS, UDC / UVigo).

## `~/selected-work`

### [FirmLab](https://github.com/founder4/firmlab) — firmware analysis workbench

A local-first tool that takes a firmware image and returns a structure map, an entropy graph, the extracted filesystem, secrets, an SBOM with known-CVE matches and an architecture-aware emulation ladder. TypeScript, 3,100+ tests, validated against a locked corpus of public firmware samples.

### Best Bachelor's Thesis — Cátedra R en Ciberseguridade, 2025

*"Security analysis and vulnerability research in IoT devices"*, graded **9.8 / 10**. A practical, low-cost methodology for assessing home-IoT firmware security.

## `~/focus`

- 🔬 **Firmware & embedded RE** — SPI flash dumping (CH341A), image extraction and carving, static/dynamic reversing of MIPS / ARM / Xtensa targets.
- 📡 **IoT security research** — auth bypasses, crypto misuse, exposed debug/diagnostic surfaces and OTA weaknesses on embedded devices.
- 🛡️ **GRC & security governance** — risk analysis (MAGERIT), system hardening, secure architecture, Zero Trust; ENS · NIS2 · ISO 27001/22301.
